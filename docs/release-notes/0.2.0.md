# DiscDock 0.2.0

DiscDock 0.2.0 adds audio playback, a searchable in-app changelog, expanded contextual Help, and Arch Linux packaging suitable for Omarchy.

## Highlights

- Play catalogued audio files in the app.
- Read and search the changelog alongside contextual Help in a resizable slide-out panel.
- See the application version in the top toolbar.
- Create a Linux desktop shortcut and run the Arch/Omarchy development build with isolated development data.
- Build an installable Arch `.pkg.tar.zst` from the electron-builder payload with correct package ownership and optional device/audio-CD utilities.
- Updated Electron and `better-sqlite3` to compatible releases.

## Arch Linux package

The `.pkg.tar.zst` is the installable Arch package. The `.pacman` artifact is an intermediate payload used by the AUR recipe. The initial package supports x86_64.

## Data and limitations

DiscDock stores its catalog locally and catalogs file metadata; it does not back up original file contents. Linux is the supported release platform. Large full-hash scans and some end-to-end workflows still need broader acceptance testing.
